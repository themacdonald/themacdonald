## Flagship projects

### BiasGuard
Framework for model bias detection and mitigation.

- Metrics: disparate impact, equal opportunity, calibration gaps
- Mitigation: reweighting, thresholding, adversarial debiasing
- Output: reproducible reports + CI checks for regression in fairness metrics

### FeedbackLoop
RLHF training pipeline for recruiting assistants.

- Collect preference data (pairwise + rubric)
- Train reward model
- Optimize policy with PPO-style updates
- Track quality: win-rate, safety flags, drift, annotator agreement

### ConfidenceCoach
AI-powered tool to combat impostor syndrome.

- Skill gap analysis
- Personalized “evidence-based” confidence notes
- Measurable progress loops (goals, streaks, reflection)
